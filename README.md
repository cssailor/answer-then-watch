# 答完再看 · AnswerThenWatch

**让孩子先答题，再看电视。**

一台常开的 NAS / 树莓派 + 一个隐藏入口的 Fire TV 答题 App，把「看电视」变成
「每看一段，先答对题」。家长后台能看知识点掌握、错题本、观看时长，并一键导出
可交给大模型分析的学习报告。

> 适合家里有 Fire TV Stick、希望限制观看时长并顺带复习的家长。
> 完全自托管，数据留在自己的 NAS 上，不依赖任何云服务。

---

## 它解决什么问题

- 孩子看电视停不下来，定时器、口头约定很难执行
- 强行关机容易冲突，希望有一个「答完就能继续」的规则
- 看完之后不知道孩子哪里薄弱，错题也没有沉淀
- 希望控制的是「看电视」这件事，而不是把电视彻底锁死

**答完再看**的做法：视频每看满一段时间就暂停，弹出全屏选择题；答对继续，
答错换题。后台记录每个知识点的掌握度、错题本和观看时长，家长可以随时调整
规则、导出学习报告。家长自己需要用电视时，输入 PIN 就能退出并暂停管控。

## 核心功能

- **检查点答题**：每 N 分钟暂停视频，答对才继续；错题优先出题
- **多题 / 连续答对**：一次暂停可以要求答对 1–5 题，并可要求连续答对
- **单次观看上限**：连续看满 X 分钟强制进入刷题模式，不能继续看视频
- **两次观看间隔**：一次看完后，在 Y 分钟内又开始看，直接进入循环刷题
- **家长退出**：电视上输入 PIN 可退出，本次开机/会话内不再检查
- **默认受控**：关机再开机后自动恢复管控，下次开电视默认受控
- **家长后台**：知识点掌握、错题本、题库增删改 / JSON 导入导出、观看统计
- **学习报告**：Markdown（自带给大模型的提示词）/ JSON，按 7/30/90 天或全部导出
- **电视端 APK 可配置服务器地址**，Docker 一键部署，数据本地 SQLite

## 它是怎么工作的

```
Fire TV Stick 4K ──ADB(局域网)── NAS / 树莓派（控制器）
        │                              │
        └──── HDMI ──── 电视            └── 家长后台 + SQLite + 题库
```

- 后端控制器每 2 秒读取 Fire TV 的播放状态和前台 App
- 到检查点时用 ADB 暂停视频、拉起答题 App
- 答题 App 启动时抢音频焦点，让播放器自己暂停（对云视听这类不响应媒体键的 App 也有效）
- 答题 App 只负责显示和提交；题库、判题、统计、报告都在后端
- 电视真正播放视频的仍是 Fire TV 上的原生 App（云视听、Netflix、YouTube 等）

## 快速开始

### 你需要

- 一台 7×24 常开的 NAS / 树莓派 / 小主机，支持 Docker
- 和电视在同一局域网的 Fire TV Stick（4K / 4K Max）
- Fire TV 打开 ADB 调试：
  设置 → My Fire TV → 关于 → 连点设备名 7 次 → 开发者选项 → ADB 调试

### 1. 启动后端

```bash
git clone https://github.com/<your-name>/answer-then-watch.git
cd answer-then-watch
cp .env.example .env
# 编辑 .env，把 FIRE_TV_IP 改成你的 Fire TV IP
docker compose up -d --build
```

第一次连接时电视会弹 ADB 授权框，用 Fire 遥控器点「允许」。
日志里出现 `Fire TV 连接正常` 后，打开：

```
http://<NAS的IP>:8765/
```

默认 PIN `1234`，第一次进入后请在「设置」里改掉。

### 2. 安装电视端 APK

```bash
cd tvgate-quiz
./install.sh <Fire TV 的 IP>
```

APK 会隐藏桌面入口，正常由控制器拉起。首次手动打开时会提示填写服务器地址；
也可以长按答题界面右下角的「家长退出」修改服务器地址。

> 没有 Android 构建环境？可以直接下载 Releases 里的 `app-debug.apk`，
> 或者在本地用 Android SDK 执行 `./gradlew assembleDebug`。

### 3. 在后台设置规则

打开「设置」页，建议先设：

- 检查间隔：600 秒（10 分钟一次）
- 单次观看上限：30 分钟（需要强制刷题时）
- 两次观看间隔：30 分钟（防止刚关就重开）
- 每次暂停需答对题数：1
- 家长退出：本次会话不检查（关机后恢复）

### iStoreOS / OpenWrt 注意

iStoreOS 的 `/mnt` 是 4MB tmpfs，**不要**把部署放进去；使用持久化的 `/overlay`：

```bash
REMOTE_DIR=/overlay/tvgate ./tvgate/deploy-istoreos.sh
```

并且 iStoreOS 自带 ADB server，需要用 bridge 网络（见 [tvgate/NAS-DEPLOY.md](tvgate/NAS-DEPLOY.md)）。

## 设置说明

设置页分为「**通用设置**」（题目与答题相关）和「**高级设置**」（时长、ADB 与系统行为）。

很多人会混淆「检查间隔」和「观看会话间隔」，这里说清楚：

| 设置 | 含义 | 默认 |
|---|---|---|
| **检查间隔**（秒） | 看视频时每隔多久弹一次题。是**弹题频率**，不是总时长上限。 | 600 |
| **观看会话间隔**（秒） | **只用于统计**：中途离开超过多少秒就算「新的一次观看」。它不影响弹题。 | 180 |
| **ADB 轮询间隔**（秒） | 控制器多久读取一次电视状态。越小反应越快，ADB 调用越频繁。 | 2 |
| 单次观看上限（分钟） | 连续观看达到这个时长后强制进入刷题模式；0 = 关闭。 | 0 |
| 强制刷题时长（分钟） | 触发单次上限后，强制刷题多久；结束后才能继续看。 | 10 |
| 两次观看间隔（分钟） | 一次观看结束后，在这个时间内又开始看 → 直接进入循环刷题，直到间隔结束；0 = 关闭。 | 0 |
| 每次暂停需答对题数 | 一次暂停要答对几题才恢复播放。 | 1 |
| 必须连续答对 | 勾选后答错会清零进度；不勾则按累计答对数算。 | 开 |
| 优先出错题本 | 每次出题先从未掌握、且已到复习时间的错题里选。答错后推迟到第二天才再次优先，本次观看不会重复出同一道错题；答对即移出错题本。 | 开 |
| 错题复习延迟（小时） | 答错的题等多久才再次被优先出题。默认 24 = 第二天，48 = 第三天。 | 24 |
| 家长模式闲置重置 | 家长退出后，电视闲置超过这个时间自动恢复管控；关机再开机也会恢复。 | 10 |
| 最高难度档 | 控制器最多用到第几档难度；题库目前适合 1–3。 | 3 |
| 每题限时 | 超时按答错处理。 | 120 |
| 家长端 PIN | 后台登录和 TV 端退出共用；4–12 位字母数字。 | 1234 |

## 家长退出

答题界面右下角有一个「家长退出」按钮：

1. 遥控器按向下键走到该按钮，按 OK
2. 输入家长端 PIN，确认
3. App 退出、视频恢复，本次开机/会话内不再弹题（家长模式）
4. **关机再开机**后自动恢复管控；电视**睡眠/关屏**也会立即恢复；闲置超过「家长模式闲置重置」也会恢复
5. 也可以在后台「设置」页点「立即恢复管控」提前结束

家长退出状态存在数据库里，控制器重启也不会丢；家长模式下不计入孩子的观看统计。

## 错题优先的节奏

错题优先不是「答错后立刻又出同一道题」，而是按复习节奏来：

1. 答错一道题 → 进入错题本，并记下「下次可复习时间」（默认 24 小时后 = 第二天）
2. 本次观看内不会再优先出这道题（避免反复刷同一道题）
3. 到复习时间后，错题本里的题会被优先出；答对即移出错题本
4. 再次答错则计数 +1，并重新推迟到下一个复习周期

「错题复习延迟」可在设置里改（24 小时 = 第二天，48 小时 = 第三天）。

## 限制与已知问题

这是一个**自托管、面向折腾型家长**的项目，不是开箱即用的商业产品：

- **必须有常开后端**：控制器跑在 NAS / 树莓派上；后端宕机时无法弹题（视频本身仍可播放）
- **依赖 ADB**：需要开启 Fire TV 的 ADB 调试，并在电视上授权一次
- **Fire OS 版本差异**：在 Fire TV Stick 4K（AFTMM / Fire OS 6）上验证；
  更新机型的后台限制、ADB 行为可能不同
- **暂停依赖音频焦点**：云视听已验证可暂停；少数 App 不响应音频焦点或媒体键
- **时长是「前台视频 App 时间」**：云视听这类不注册 MediaSession 的 App，
  暂停/菜单时间也会被计入；不是精确的播放时长
- **答题 App 不能覆盖在其他 App 之上**：它通过切换前台 Activity 显示，
  不是悬浮窗；因此需要控制器用 ADB 拉起
- **家长出口是软约束**：孩子如果强制停止 App 或拔电源，控制器会尝试重新拉起，
  但没有设备所有者/root 级别的硬锁
- **单设备统计**：目前是全局一份数据，没有按孩子/多电视区分
- **题库是仿真题**：按人教版/部编版四年级下册课标生成，不包含受版权保护的试卷原文；
  可以自行扩充或接入 AI 出题
- **局域网 HTTP**：PIN 在局域网内明文传输，请只在家庭网络使用，
  不要将 8765 / 5555 端口映射到公网
- **APK 是 debug 构建**：适合个人侧载；正式分发请自行签名 release 包

## 常见问题

**Q：为什么 Fire TV 桌面上看不到答题 App？**
A：故意隐藏了桌面入口，避免孩子直接打开。控制器通过 ADB 拉起；
手动打开可以用 `adb shell am start -n com.tvgate.quiz/.QuizActivity`。

**Q：孩子按 Home 键怎么办？**
A：控制器每 2 秒检查前台，发现不是答题 App 会重新拉起。返回键被 App 屏蔽。

**Q：家长怎么正常使用电视？**
A：答题界面右下角「家长退出」，输入 PIN，进入家长模式。

**Q：某个 App 暂停不了？**
A：先运行 `python3 tvgate/firetv_probe.py --ip <TV_IP> --pause-test` 测试；
如果该 App 不响应媒体键，答题 App 的音频焦点通常仍能让它暂停。
如果都不行，请提 issue 并附上 App 名称。

**Q：怎么更新题库？**
A：后台「题库」页可以直接增删改；也可以导出/导入 JSON；
批量修改可编辑 `tvgate/questions.json` 后点「从 questions.json 重新载入」。

**Q：数据在哪？怎么备份？**
A：`data/tvgate.db`（作答、错题、观看、设置）；整个 `data/` 目录做快照即可。

**Q：可以不用 NAS 吗？**
A：当前版本需要一个常开的后端。把全部功能塞进 APK 技术上可行，但会失去
外部看门狗和 ADB 权限，Fire OS 新机型的后台/悬浮窗限制会让可靠性明显下降；
因此本项目默认保留「后端 + 瘦 APK」。

**Q：支持其他电视/盒子吗？**
A：控制器通过 ADB 操作 Android 设备；电视端 APK 是 Android TV 应用。
理论上可适配其他 Android TV 盒子，但启动包名、媒体键行为需要调整。

**Q：会上传数据吗？**
A：不会。后端只在你自己的局域网内提供 HTTP 接口，没有外部上报。

## 隐私

- 仓库里不包含任何 `.env`、数据库、ADB 密钥、个人 IP 或账号信息
- 运行时数据只存在你的 NAS 上
- 题库是自拟/仿真的课标同步题
- 提交 issue/PR 前，请确认没有带上 `.env`、`data/`、`adb/`、日志里的真实 IP

## 开发 / 贡献

- 后端：Python 3.11，标准库，无第三方依赖
- 电视端：单 Activity Java，无第三方库
- 本地自检：

```bash
python3 tvgate/tvgate.py --selftest      # 题库与选题逻辑
python3 tvgate/tvgate.py --quiz-test     # 本地答题 API
cd tvgate-quiz && ./gradlew assembleDebug
```

欢迎提 issue / PR，尤其是：

- 不同 Fire TV 机型 / Fire OS 版本的兼容性反馈
- 某个视频 App 无法暂停的复现信息
- 题库扩充、更多年级/学科
- 更精确的观看时长识别方式
